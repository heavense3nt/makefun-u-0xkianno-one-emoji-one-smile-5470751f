## The emoji

**🤗 — hugging face.**

One emoji, chosen with intent: a smiling face with open arms. Warm at first
glance, instantly readable by a stranger of any age, picked rather than the
default smiley, and friendly without intimacy, sarcasm or flirtation — a
welcome, not a wink.

## How it works

`main.ts` writes exactly one emoji — and nothing else, no trailing newline —
to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR` when absolute,
otherwise relative to the repository root).

```sh
node main.ts
```
